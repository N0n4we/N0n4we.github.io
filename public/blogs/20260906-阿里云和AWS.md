### 阿里云就是照葫芦画瓢，还画的不像

阿里云全面对标 AWS，云监控 -> CloudWatch、配额中心 -> Service Quotas、RAM -> IAM、CloudSSO -> IAM Identity Center、事件总线 -> EB、etc.
但是，AWS 浑然一体，阿里云一坨够吃

以 EventBridge 为例，阿里云 EB 很多事件源还要手动接入，比如云监控告警。内置事件源 `cms:CloudMonitor:AlertWebHook` 压根不是告警事件，是回调事件。
而 AWS 没有事件源这个概念，默认把全平台事件都在 EB 流通，包括 CloudWatch 告警。
我觉得这才是 EB 的意义啊，都 **事件总线** 了，还不包含平台事件，那我怎么不自己搭总线
